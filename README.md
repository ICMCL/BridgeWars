# Bridge Wars（战桥）—— Minecraft Java 版 26.3 数据包

## 【安装】
1. 把 bridge-wars.zip 直接放进 存档文件夹/datapacks/（可以不解压）。
2. 战场维度 zq:arena、设置/商店对话框和自定义附魔都需要在进入世界时加载：安装或更新数据包后【退出世界再重新进入】（不是 /reload）。
   进入时可能提示"实验性设置"，点继续即可。
3. 管理员输入 /function zq:install （每个世界只需一次）。

## 【讲台无反应 / 数据包验证失败】
- 更新时替换存档 datapacks 里的旧包，不要同时保留压缩包和解压版；然后退出世界并重新进入。
- 管理员可用 /function zq:menu 检查设置菜单。如果提示“未知的函数”，查看此游戏实例 logs/latest.log 中的注册表或函数加载错误；不要反复运行安装命令，也不需要删除存档。
- 26.3 的附魔伤害条件使用 type 字段，伤害类型标签引用要带 #；旧格式会造成数据包验证失败。本包已按此格式修正。

## 【大厅】（主世界 y=150）
- 默认身份是旁观者。站上红色/蓝色区域 = 选队；灰色区域 = 取消选队（旁观）。
- 右键讲台 = 设置（规则开关、阶段时间、查看/恢复默认），对下一局生效。
- 按绿宝石块上的按钮开始游戏（两队都至少要有 1 人）。旁观者以旁观模式观战。
- 强制结束：/function zq:game/stop

## 【基本规则】
- 战场在独立维度，玩家是冒险模式：只能用镐子挖玩家方块，岛屿本体和基地挖不动。TNT 会伤人并破坏附近约 3 格的玩家方块（基岩除外），岛屿本体、出生点和旗台受保护；原版爆炸波及的岛体会在下一次保护 tick 复原，搬岛期间在分片结束后复原。
- 掉下岛面 40 格（y<60）开始快速掉血；飞出场地边界也会掉血。
- 回血靠饱食度（原版自然回血），给牛肉排充饥：开局 8 块，每 30 秒补 1 块，最多 8 块。
- 夺旗：站上敌方旗台（岛尾金块）拿旗，带回自家旗台。获胜条件可在设置里选。
- 扛旗：原来的物品先收起来，只剩旗帜、24 个方块（每 2 秒补 1）和 2 块牛肉排；减速 II、发光、挖掘疲劳，
  只保留防御升级，不能用商店和脚下生桥。旗台周围允许搭建和封旗，旗帜本身和脚下金块仍受保护。
  旗手死亡或成功夺旗后，原来的物品原样还回来。
- 基地 = 出生点 3×3 彩色釉陶地板，每 tick 复原，上方方块会被清掉。
- 岛屿 17×9。商人站在旗帜后面（岛的最后端），旁边有箱子矿车商店。右键箱子矿车打开 27 格容器，取出商品图标即可扣款发货；包含道具、团队升级和免费换职业。金币仍为全队共享，价格见物品名称/说明，余额看右侧计分板。
  图标是购买凭证，不是免费商品；点击取出即可购买，鼠标上拿着的图标也会自动处理。购买需在自家商店 5 格内、处于冒险参战状态且未扛旗；敌队或无效位置的图标会回收且不扣款。金币不足或已满级时不发货，显示原因。
  这是多人共用的实体容器，不是私人储物箱：不要存放自己的物品。空商品格每 tick 补货；同一图标每人每 tick 最多处理一次，重复取出会重复购买。关闭商店时只允许免费换职业。右键商人在商店开启时提示箱子位置，商店关闭时仍可直接打开换职业窗口。
- 更新此版本后退出世界再进入，并开始新的一局，才会生成箱子商店和岛屿保护模板；不必重新安装或删除存档。
- 金币全队共享：开局 5；每 30 秒 +1；击杀 +3；对方旗手死亡（任何原因）+5；第一次拿到对方旗 +5（每局一次）。
- 丢出的物品会弹回给丢的人，2 秒没捡回就删除。

## 【方块】越贵越难挖（铁镐 / 建造者镐；徒手挖不动）
- 混凝土 0.3 / 0.15 秒，陶瓦 0.75 / 0.3，石砖 1.5 / 0.6，末地石 3 / 1.2，原木 6 / 6。
- 消除方块箭耐久 10：混凝土/玻璃/史莱姆 1，陶瓦 2，石砖 3，末地石 4，原木 10。

## 【设置项】（右键大厅讲台）
- 桥：不生成 / 分阶段（无→间断→完整→基岩）/ 开局就有完整桥（可破坏，不会变基岩）
- 两座岛缓慢靠近、商店、毒墙收拢、死斗、死亡递增复活：各自开关
- 获胜条件：带回对方旗帜即可 / 自家旗在家时带回才算
- 阶段时间：间断桥、完整桥、基岩桥、两岛开始靠近、靠近间隔、毒墙开始收拢、收拢用时、死斗开始（每项 5 档时间，桥的三个阶段另有“关闭”选项）
- 桥的计时：间断桥从开局算；完整桥从间断桥出现算；基岩桥从完整桥出现算。例如选 3分/6分/10分，实际在开局后 3分/9分/19分触发，不再自动补 30 秒。更新前保存的选项档位保留，后两项按新的阶段时长解释。
- 关闭某个桥阶段时，跳过它和它的等待时间，也不发送该阶段的倒计时提醒；下一开启阶段从上一个开启阶段算，没有则从开局算。例如关闭间断桥、完整桥选 6 分钟，则开局后 6 分钟直接出现完整桥；只开启基岩桥时，到时直接生成基岩桥。三个阶段全关则不生成桥；这些选项仅在桥规则为“分阶段”时生效。
- 两岛开始靠近、毒墙开始收拢、死斗开始仍从开局算，互不串联；靠近间隔和收拢用时仍为间隔/持续时间。“查看当前设置”和开局摘要显示桥的开局后累计触发时间。

默认：四个场地压力机制（桥 / 两岛靠近 / 毒墙 / 死斗）全部关闭，只开商店和死亡递增复活，
也就是一张纯粹的「自己搭桥打过去抢旗」的图；要哪个机制就在讲台里单独打开。
各机制打开后的默认时间：桥各阶段等待 3分/6分/10分，即开局后 3分出现间断桥、9分补全、19分变基岩（间断桥为铺 2 空 3）；两岛 2 分钟起每 30 秒靠近 2 格（最多 20 次）；
毒墙 10 分钟开始从两侧收拢，3 分钟后只剩中间 3 格宽（z=-1..1），收完后墙外持续掉血（若同时开了死斗，则直接进入死斗）；
死斗 12 分钟；获胜=带回即可。死斗开始后大厅里的人不能再进场。
